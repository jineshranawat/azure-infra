A. Why you do not see any Purview pipeline

Common confusion: There is no pipeline literally named “Purview”. The Purview module is the set of pipelines whose names start with pl_gov_ inside ADF folder 13-governance-purview.

B. Deploy the Purview pipelines (if folder is empty)

From the repo root on Windows:

git pull az login infra-walkthrough.cmd --phase 3

Or only the ADF lab:

deploy-shared-adf-lab.cmd

Or force governance deploy + run the demo:

purview-demo.cmd

Success signal in the terminal: lines like Governance pipeline pl_gov_01_… … pl_gov_06_… and later ADF … linked to Purview pview….

Verify with Azure CLI (optional)

az datafactory pipeline list -g rg-shared-class1 --factory-name adf-shared-qgr7mj --query "[?contains(name,'pl_gov')].name" -o tsv

You should see six names. If the list is empty → re-run phase 3 / deploy-shared-adf-lab.cmd.

D. Every Purview-related pipeline (what each does)

pl_gov_06 (MASTER) ├─ pl_gov_01 Bronze land (Copy incoming → loaded) ├─ pl_gov_02 Silver cleanse (Mapping Data Flow) ├─ pl_gov_03 Gold aggregate (Mapping Data Flow) ├─ pl_gov_04 Catalog / glossary JSON (Lookup + variables) └─ pl_gov_05 Purview discovery + lineage Copy (Get Metadata ×3)
PipelinePurview idea it teachesWhat happens
pl_gov_01_medallion_bronze_land Data asset + classification tags Copy bronze incoming → loaded; user properties mark medallion layer
pl_gov_02_medallion_silver_cleanse Lineage via Data Flow Runs df_01_bronze_cleanse → silver cleaned
pl_gov_03_medallion_gold_aggregate Lineage to gold layer Runs df_02_channel_aggregate → aggregates (gold layer path)
pl_gov_04_governance_catalog_metadata Glossary / catalog workflow Reads purview_catalog_template.json from ADLS audit/
pl_gov_05_purview_discovery_lineage Scan / discovery + lineage edge Get Metadata on bronze/silver/gold folders + Copy to reinforce lineage
pl_gov_06_master_medallion_governance End-to-end demo Execute Pipeline chain 01→05. This is the one demo component.

Analogy: pl_gov_06 is the full dinner service. Purview is the guest book that records which kitchen station prepared each course.

E. Run the ready demo — detailed steps

Option 1 — one command (recommended)

cd C:\Azure\azure-infra-class git pull az login purview-demo.cmd

Option 2 — from ADF Studio UI

  1. Author → folder 13-governance-purview → open pl_gov_06_master_medallion_governance.
  2. Click Debug (or Add trigger → Trigger now).
  3. Confirm parameters: run_id=session3-lab (defaults are fine).
  4. Go to Monitor → Pipeline runs → wait until status Succeeded.
  5. Click the run → expand Activity runs → you should see Execute Pipeline for 01, 02, 03, 04, 05.

Option 3 — CLI from shared-adf-lab

cd shared-adf-lab orchestrate.cmd --run-only --run-pipeline pl_gov_06_master_medallion_governance

After Succeeded: wait 5–30 minutes before lineage appears in Purview. ADF pushes lineage asynchronously.

F. Purview portal — detailed clicks (classic only for ADF lineage)

CRITICAL: Toggle OFF “New Microsoft Purview portal”. ADF lineage does not show in the new portal.

F1 — Open classic Purview

  1. Azure Portal → search pviewrohan4hnv7s → Open Microsoft Purview governance portal.
  2. Top of screen: ensure New Microsoft Purview portal = OFF.
  3. You should be in classic Governance / Data Catalog experience.

F2 — One-time: grant ADF Data Curator (if lineage never appears)

  1. Classic portal → Data map → Access control (or Collections → Root).
  2. Root collection → Role assignments → Add.
  3. Role: Data Curator.
  4. Member: managed identity / SPN named adf-shared-qgr7mj.
  5. Save. Re-run pl_gov_06 once.

F3 — Search the catalog (not global home search)

  1. Data catalog → Overview → use the Search catalog box.
  2. Search these terms (one at a time):
SearchWhy
stsharedqgr7mjStorage account / lake assets
sample_transactionsBronze CSV — best for Lineage tab
loadedBronze loaded folder
cleanedSilver cleansed
aggregatesGold aggregates path
adf-shared-qgr7mjUsually ZERO results — not a catalog asset

F4 — Open Lineage

  1. Open a result (e.g. sample_transactions or a loaded path).
  2. Click the Lineage tab.
  3. You should see edges / process nodes for ADF Copy or Data Flow activities after sync.
  4. Compare names with ADF Monitor → pl_gov_06 activity list (same story, two portals).

F5 — Optional: register + scan ADLS if search is empty

  1. Data map → Sources → Register → Azure Data Lake Storage Gen2.
  2. Account stsharedqgr7mj → New scan → containers bronze, silver, audit → Run.
  3. Wait for scan complete → search again.
