Microsoft Purview — what to teach + one ready demo

Easy class plan for FinLedger shared estate. One demo component: ADF pipeline pl_gov_06_master_medallion_governance. Run: purview-demo.cmd

1. What & why (teach first — 10 minutes)

Purview = searchable catalog of your data estate + lineage (how data flows).

Analogy: Purview is Google for your data. ADF cooks the food; Purview is the recipe book that shows where each dish came from.

3. Trainer demo script (15 minutes)

  1. Theory — Purview = catalog + lineage (table above).
  2. Run demo — purview-demo.cmd from repo root (wait for Succeeded).
  3. ADF Monitor — open pl_gov_06 → show child pipelines 01→05 Succeeded.
  4. Classic Purview — toggle OFF “New Microsoft Purview portal”.
  5. Search catalog — type sample_transactions or stsharedqgr7mj (not the factory name).
  6. Lineage tab — show ADF as a process node on the path (wait 5–30 min after first run if empty).
  7. Optional — show audit/governance/ JSON on ADLS as the Databricks-side “manifest” story.
