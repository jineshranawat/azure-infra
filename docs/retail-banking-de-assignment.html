1. Problem statement — the overnight crisis

FinTrust Bank plc (fictional UK retail bank) cannot answer Risk/Finance questions without Excel:

  1. Yesterday’s authorised card spend by channel / MCC?
  2. Which payments failed DQ or arrived late — quarantined or polluting silver?
  3. Who breached FPS/card velocity rules for fraud review?
  4. If ADF gold fails at 02:10, who gets a ticket with the run log?

Your role: Lead Data Engineer. Deadline ~10–15 working days (trainer sets exact). Region uksouth, cheapest SKUs, synthetic data only.

Sources (CSV/JSON card · FPS · dims) → ADF / landing → ADLS bronze → DQ gate + quarantine → watermark incremental → silver (UC) → gold marts (spend · velocity · dq · audit) → Genie Agent (MI questions) → Notify on fail (Jira+mail) → Purview / pl_gov lineage story
