1. Why · What · How (plain language)

~2–3 hours reading + discussion

Why

Business users wait days for SQL tickets. Analysts rewrite the same metrics. Leadership wants self-serve answers without losing Unity Catalog governance.

What

Genie Agent = curated NL→SQL chat over UC tables/views, powered by a SQL warehouse, instructions, example SQL, and trusted assets.

How

Analyst curates 3–30 tables + examples → users ask English questions → Genie writes/runs SQL → table + summary (permissions still apply).

Analogy: Genie is a trained waiter. UC tables are the pantry. Example SQL is the recipe book. Instructions are house rules. The SQL warehouse is the stove. Guests never enter the kitchen — but they only get dishes they’re allowed to eat (SELECT / RLS).

Rename note (2026)

Genie Agents were formerly called Genie Spaces. UI and docs may show either label. Same feature family.

3b. SQL warehouse — step by step

Why

Genie-generated SQL must execute somewhere. Warehouse = Genie’s compute.

What

Pro or serverless SQL warehouse. Author’s credentials are embedded for all users’ queries; users still need data SELECT.

How

Create tiny warehouse, short auto-stop, attach in Genie Settings.

  1. Open SQL warehouses.
  2. Create SQL warehouse — name e.g. finledger-genie-wh.
  3. Prefer Serverless if available; else smallest Pro.
  4. Size: cheapest viable (2X-Small / starter). Auto-stop: 10–15 min.
  5. Create → start once → confirm Running → let it auto-stop.
Cost: Warehouses spend money while running. Class rule: warn, smallest SKU, never leave running overnight.

3c. Prepare Unity Catalog metadata (quality starts here)

Why

Genie reads comments. “amt” with no description → wrong SQL. “amount_gbp — transaction amount in GBP” → better SQL.

What

Table comment, column comments, useful views that hide messy bronze columns.

How

Catalog UI or SQL COMMENT ON / ALTER.

  1. Catalog → dbw_shared_qgr7mj.advanced_lab.channel_kpi.
  2. Add table description: what grain, what “channel” means.
  3. Comment each column in plain business English.
  4. Prefer silver/gold-style tables for Genie — not raw dumps.
-- Example pattern (names may vary) COMMENT ON TABLE dbw_shared_qgr7mj.advanced_lab.channel_kpi IS 'Channel-level KPI grain for FinLedger lab; one row per channel metric snapshot'; COMMENT ON COLUMN dbw_shared_qgr7mj.advanced_lab.channel_kpi.channel IS 'Payment channel: card, wire, or fps';

4. Create a Genie Agent — latest Databricks documentation

Source of truth (updated Jul 14, 2026): docs.databricks.com — Create and manage a Genie Agent · MS Learn (Azure) — same topic · Hub: Genie overview

Official rename: Genie Agents were formerly known as Genie Spaces. Some locale pages still say “Space” — same product. Sidebar label in current docs: Genie Agents.

4.0 Before you click New — requirements (from docs)

Technical requirements and limits

  • Unity Catalog: data must be registered to UC. You can add up to 30 tables or views per Genie Agent.
  • Compute: pro or serverless SQL warehouse. Creator needs at least CAN USE on that warehouse. Your compute credentials are embedded and used to process queries for all users.
  • Capacity: up to 10,000 conversations per agent; up to 10,000 messages per conversation.

Required permissions (to create or edit)

  • Entitlements: Databricks SQL workspace entitlement.
  • Compute: CAN USE on at least one pro/serverless SQL warehouse.
  • Data access: SELECT on the data used in the agent.
  • Genie Agent ACLs: at least CAN EDIT to edit; creators get CAN MANAGE automatically.

Partner-powered AI

Genie uses partner-powered AI features, enabled at account and workspace levels. If disabled, users may still see the Genie Agents icon but cannot access any Genie Agents. Account admin manages this — see Partner-powered AI features in Databricks docs.

4.1 Create a Genie Agent — exact 3 steps from Databricks

Class workspace: Launch workspace · then left sidebar Genie Agents · or try /genie

  1. Click Genie Agents in the sidebar.
    (If your UI still says Genie Spaces / Genie — use that entry; same feature.)
  2. Click New in the upper-right corner of the screen.
  3. Choose the data sources (Unity Catalog tables/views) you want to include. Then click Create.
    Class tip: start with 5–10 tables from dbw_shared_qgr7mj.advanced_lab + cost_lab (hard max is 30; fewer = better quality).
Proof (docs path done): A new Genie Agent opens and Genie Code typically launches automatically.

4.2 Set up with Genie Code (automatic after Create)

Per docs: when you create an agent, Genie Code launches automatically. It reads your data and suggests context (table descriptions, example queries). Review suggestions → accept the ones you want → reject the rest. To fill a gap, describe the context you want Genie Code to add.

You can also ask Genie Code to create an agent when you do not yet know which tables to use: describe business domain, questions, and data; it identifies sources, confirms with you, and builds the agent.

# Official-style Genie Code prompt (adapt for FinLedger) Create a Genie agent for FinLedger ops that answers questions about channel KPIs, payment pulses, chargeback estimates, DQ metrics, and SCD2 channel history. Use tables in catalog dbw_shared_qgr7mj schemas advanced_lab and cost_lab.
Before sharing (Databricks recommendation): add example SQL queries, instructions, and knowledge store configurations to improve accuracy — see Tune Genie Agent quality.

4.3 Review query suggestions (Data / Instructions panel)

When you add data assets, Genie searches popular workspace queries on those assets (using your credentials; you need at least CAN VIEW on those queries). If found, a notification appears on the Data tab of the Instructions panel → click Review.

  1. Title is prepopulated with a question — edit phrasing if needed.
  2. Code shows suggested SQL (not editable in the review dialog). Expand with … more lines.
  3. Optional: open SQL query in Query history if you have permission.
  4. Click Accept or Reject.
  5. Expand other suggestions and review each.

Accepted queries become editable example SQL on the agent. If none appear: missing query ACL, no prior queries on those tables, write-only queries ignored, or queries only on tables not attached to the agent.

4.4 Manage data objects

  1. Click Configure → Data.
  2. Add more tables/views, or remove with the control next to a table name.
  3. Click a table name → Overview (columns, types, descriptions) and Sample data.
Docs note: Genie can query tables beyond those explicitly added if users prompt joins / edit SQL and have UC access. Access is controlled by Unity Catalog, not by “hiding” tables in the agent alone.

5. Tune quality — where the real work is

~6–9 hours across examples + trusted assets

Why

Out-of-box Genie is average. Tuned Genie with examples is what finance will trust.

What

Text instructions, example SQL, UC functions, knowledge store joins/measures/filters.

How

Configure → Instructions → Text / SQL Queries tabs; iterate from wrong answers.

MS Learn — Tune quality · Databricks tune quality · Best practices

5.1 Text instructions (examples)

- Currency is GBP unless the user asks otherwise. - Channels are only: card, wire, fps. - "Yesterday" = previous calendar day in UTC. - Never invent rows; if empty, say empty and list filters used. - Prefer advanced_lab.channel_kpi for channel rollups. - When summarizing, lead with the number, then the breakdown.

5.2 Example SQL (highest impact)

  1. Configure → Instructions → SQL Queries.
  2. Add example. Title = how a business user asks (not “Q3 report”).
  3. Paste tested SQL against UC.
  4. Ask the title verbatim → then paraphrase → refine.
-- Title: How many rows are in channel_kpi? SELECT COUNT(*) AS row_count FROM dbw_shared_qgr7mj.advanced_lab.channel_kpi;

5.3 Trusted assets

Parameterized examples and UC SQL functions whose logic you verified. When Genie uses them exactly, answers can show as verified.

  • Users need EXECUTE on functions used as trusted assets.
  • Authors need CAN EDIT on the agent to add/remove them.

6. Agent mode (multi-step research)

~3 hours

Why

One-shot SQL fails on “investigate anomalies across KPIs and cost.” Need plan → many queries → report.

What

Agent mode: multi-step reasoning, hypothesis testing, citations, longer runtime.

How

Open agent → Agent mode icon in chat → ask a data-driven exploratory question.

  1. Open your Genie Agent chat.
  2. Click the Agent mode icon in the chat box.
  3. Ask e.g. “Compare channel KPI pulse volume vs chargeback estimates and highlight anything unusual.”
  4. Wait; optionally Answer now to stop early with partial evidence.
  5. Read final report + citations + supporting tables.
Agent mode uses the same curated context as normal Genie — tuning still matters.

7. Share, clone, export — latest docs steps

Official: Create and manage — Share / Clone / Export

How compute + data work when shared (docs)

  • Queries run with the embedded compute credentials of the author who set the warehouse.
  • End users do not need warehouse CAN USE.
  • Each user’s own UC data credentials apply — they only see allowed rows; no access → empty response.
  • Use Unity Catalog row filters / column masks to restrict data per user inside the same agent.

Consumers need: consumer or Databricks SQL entitlement · SELECT on UC objects · Genie ACL at least CAN VIEW / CAN RUN (same abilities per ACL table).

Share with specific users or groups

  1. Click Share.
  2. Enter users or groups → Add → set level: CAN MANAGE, CAN EDIT, CAN RUN, or CAN VIEW.
  3. Use Copy link at the bottom of the Share dialog for a shareable URL.

Share with all account users

  1. Share → select All account users → set permission level.

New agents save to your user folder by default and inherit folder permissions. Agents can also share individual conversations.

Clone (exact docs steps)

Copies: tables, settings, general instructions, example SQL, SQL functions. Does not copy: chat threads, Monitor tab data.

  1. Open the Genie Agent.
  2. Click the kebab menu (⋯) upper-right.
  3. Click Clone.
  4. (Optional) New name and workspace folder.
  5. Click Clone.

Export as metric view (exact docs steps)

  1. Open the Genie Agent.
  2. ⋯ → Export to metric view.
  3. Select path for the new metric view.
  4. (Optional) Open Genie Code to refine the definition.
  5. Click Create.

Test loop (classroom)

  1. Ask each Common question verbatim.
  2. Paraphrase once.
  3. Ask out-of-scope — expect refuse/empty, not fiction.
  4. Wrong answer → add example SQL / instruction → retest (see Tune quality).

9. Genie Agents API (conversation + management)

~3 hours

Why

Embed Genie in apps, CI create/update agents, orchestrators (like genie-lab).

What

REST: start-conversation, messages, create/update spaces; also Databricks SDK w.genie.

How

Curate agent in UI first → then call Conversation API with space_id + token.

POST /api/2.0/genie/spaces/{space_id}/start-conversation Authorization: Bearer <token> {"content":"How many rows are in advanced_lab.channel_kpi?"}
