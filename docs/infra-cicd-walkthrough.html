C. Concept cards (teach before each phase)

Resource Group

One fenced plot — cost and lifecycle as one unit.

Bicep + Incremental

Blueprint. Azure updates what changed — does not build a second house next door.

az deployment group create --mode Incremental ...

Key Vault + scope

Locked cupboard. Never hard-code secrets in notebooks.

ADLS medallion

Fridge shelves: bronze raw, silver cleaned, gold plated, audit rejects.

ADF

Manager timetable — Copy, Notebook, Wait, ForEach. Pay per visit + van hours.

Databricks

Kitchen. DBUs = taxi meter; Azure VMs = petrol.

SQL Basic

Small office ledger for watermarks — cheap fixed tier.

Idempotency

Press Save twice — still one document. Re-run = same end state.

D. Three layers of release

1. INFRA (rarely) Bicep Incremental provision-shared.cmd / --phase 1 2. LAB ASSETS (often) Notebooks + secrets release.cmd databricks 3. PIPELINE (often) ADF in place release.cmd adf BOTH (classroom) build+DBX+ADF release.cmd medallion-deploy + COOK (optional) Databricks job release.cmd medallion

Conveyor: reprint recipes → restock shelf → update manager checklist → optionally cook one dinner.

Databricks incremental (overwrite, not copy)

Import uses overwrite on the same path (e.g. /Shared/day9/cost_management_master). Re-release does not create … (1).

  1. Edit builder or notebook source in git
  2. git commit + push origin + class
  3. .\release.cmd databricks
  4. Studio → /Shared/day9/ → Run all
day9\orchestrate.cmd --deploy deploy-shared-lab.cmd → scripts\deploy_shared_lab.py

Specialised labs after check-in:

  • python scripts\deploy_cost_management_lab.py
  • python scripts\deploy_system_tables_lab.py
  • python scripts\deploy_perf_databricks_adf_lab.py
  • python scripts\deploy_spark_dag_problems_lab.py
  • python scripts\ensure_cost_lab_secrets.py (SPN into finledger)

ADF incremental (in place, skip SQL)

Redeploys linked services and pipelines on adf-shared-qgr7mj. Classroom default: --skip-sql.

  1. Edit pipeline / generator in shared-adf-lab/
  2. Docs-as-code in same commit
  3. .\release.cmd adf
  4. ADF Studio → Author → Debug / Trigger
  5. Optional smoke: shared-adf-lab\orchestrate.cmd --run-pipeline pl_01_bronze_copy
adf-full only when SQL Bicep, firewall, or first-time SQL changed — not every commit.

Definition of Done

  1. Code + docs on main, pushed to origin and class
  2. Correct release.cmd … succeeded
  3. Verify checklist signed off
  4. Same release command is safe to re-run (idempotent)

Whiteboard close

Bicep = blueprint Incremental = renovate, don't rebuild next door deploy-shared = furniture / recipe books on shelves ADF = manager timetable Databricks = kitchen (DBU meter) release.cmd = CI/CD conveyor (build → deploy → optional cook) git main = single source of truth
